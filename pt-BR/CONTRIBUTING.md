## 🚀 Como Contribuir

1. **Faça Fork do Repositório**
   ```bash
   git clone https://github.com/yourusername/tech-news-hub.git
   cd tech-news-hub
   ```

2. **Crie um Novo Branch**
   ```bash
   git checkout -b add-new-source
   ```

3. **Faça Suas Alterações**
   - Adicione fontes aos arquivos de categoria apropriados
   - Siga as diretrizes de formato abaixo
   - Teste todos os links para garantir que funcionem

4. **Commit Suas Alterações**
   ```bash
   git add .
   git commit -m "Adiciona [Nome da Fonte] em [Categoria]"
   ```

5. **Push e Crie PR**
   ```bash
   git push origin add-new-source
   ```
   Então crie um Pull Request no GitHub

## ✅ Diretrizes de Contribuição

### Padrões de Qualidade

**✅ INCLUIR:**
- Fontes de alta qualidade e confiáveis
- Blogs/sites ativos (atualizados nos últimos 6 meses)
- Conteúdo gratuito ou freemium
- Fontes em inglês (principalmente)
- Descrições claras e precisas
- Links funcionando

**❌ NÃO INCLUIR:**
- Conteúdo promocional ou spam
- Conteúdo pago (a menos que claramente indicado)
- Blogs inativos (6+ meses sem atualizações)
- Blogs pessoais sem conteúdo substancial
- Fontes duplicadas já listadas
- Links de afiliados (a menos que divulgados)

## 📝 Adicionando uma Nova Fonte

### Modelo de Formato

Ao adicionar uma fonte, use este formato markdown:

**Para tabelas:**
```markdown
| [Nome da Fonte](https://example.com/) | Breve descrição do conteúdo | Frequência de Atualização |
```

**Para listas:**
```markdown
- [Nome da Fonte](https://example.com/) - Descrição do que a torna valiosa
```

## 🗂️ Sugerindo uma Nova Categoria

Se você acha que estamos perdendo uma categoria importante:

1. **Abra uma Issue** com:
   - Nome da categoria
   - Breve descrição
   - Por que é necessária
   - Pelo menos 10-15 fontes de qualidade para a categoria

## 🔗 Reportando Links Quebrados

Encontrou um link quebrado? Ajude-nos a corrigir!

1. **Abra uma Issue** intitulada: "Link Quebrado: [Nome da Fonte]"
2. **Inclua:**
   - Link que está quebrado
   - Categoria/arquivo onde está localizado
   - Substituição sugerida (se disponível)

**Ou** envie um PR com a correção diretamente!

## 🎯 Melhores Práticas

### Ao Adicionar Fontes

1. **Verifique o Link** - Certifique-se de que funciona
2. **Verifique Duplicatas** - Pesquise o arquivo primeiro
3. **Use Formatação Adequada** - Siga os padrões markdown
4. **Escreva Descrições Claras** - Ajude os usuários a entender o valor
5. **Coloque na Categoria Certa** - Use a seção mais apropriada
6. **Mantenha Ordem Alfabética** - Dentro das subseções quando possível

### Diretrizes de Descrição

**Boa Descrição:**
```markdown
- [Blog do Martin Fowler](https://martinfowler.com/) - Artigos aprofundados sobre design de software, padrões de arquitetura e refatoração
```

**Descrição Ruim:**
```markdown
- [Blog do Martin Fowler](https://martinfowler.com/) - Blog sobre programação
```

## 📜 Código de Conduta

### Nosso Compromisso

Estamos comprometidos em fornecer uma experiência acolhedora e inclusiva para todos.

### Comportamento Esperado

- Seja respeitoso e construtivo
